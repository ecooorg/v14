# Deploy

## Requirements

- Node 20+
- Env: `SESSION_SECRET`, `TESTER_CODES`, `GEMINI_API_KEY`
- Optional: `PUBLIC_ORIGIN`, `GLOBAL_DAILY_CALL_CAP`, `AI_ENABLED`

## Railway / similar

1. Connect repo
2. Set env vars
3. Start command: `npm run start`
4. Build: `npm run build` (if static assets needed)

App has no host-specific code (INF-9).
